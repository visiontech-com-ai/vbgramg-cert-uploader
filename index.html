VB-G RAM G · Certificate Auto-Fill

Chrome / Edge add-on for the Work Entry page

Fills all 8 certificate blocks on the VB-G RAM G Work Entry page in one click — the same signing-authority details in every block — and attaches the certificate PDFs from a folder. Oversized scans are compressed to fit the server’s size limit automatically.

Download for Chrome / Edge
latest release downloads: —

One-click fill

The same Name / Designation / Department / Mobile / Email into all 8 blocks, set once in the add-on’s settings.

Folder → PDFs

Pick a folder; each PDF is matched to its block by the number 1–8 in its name.

Auto-compress

Scans over the ~1 MB server limit are re-rendered smaller on your PC — nothing is uploaded anywhere.

Install (about a minute)

  1. Download the ZIP above and unzip it to a permanent folder (e.g. C:\VBG\vbg-cert-autofill).
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and select the vbg-cert-autofill folder.
  4. Click the add-on’s toolbar icon and enter your signing details once. Then open the Work Entry page and use the panel.
