Certificate Auto-Fill

VB-G RAM G · Work Entry — install & use guide

This add-on fills the 8 certificate blocks on the Work Entry page in one click — the same Name / Designation / Department / Mobile / Email in every block, and it attaches your 8 certificate PDFs. You type your details once in the extension’s settings; the browser remembers them. The DPR and Convergence blocks are set to Yes automatically so their uploads are included.

Part A · Install once (about 1 minute)

1

Save the folder somewhere permanent

Copy the vbg-cert-autofill folder to a fixed place, e.g. C:\VBG\vbg-cert-autofill. Do not delete or move it after installing — the browser reads the add-on from this folder every time.

2

Open the Extensions page

In the address bar type chrome://extensions and press Enter.
On Microsoft Edge, type edge://extensions instead — every other step is the same.

3

Turn on Developer mode

Find the Developer mode switch (top-right in Chrome, left side in Edge) and turn it ON. New buttons appear.

4

Click “Load unpacked” and pick the folder

Click Load unpacked, then select the vbg-cert-autofill folder and choose Select Folder.

5

Done — you’ll see the blue ✓ icon

The add-on is installed. It only wakes up on the Work Entry page (…/vbgramg/work_entry.aspx) and does nothing on any other website.

Part B · Name your certificate PDFs (per scheme)

The PDFs are different for every scheme — that’s fine. Put all 8 in one folder. Each file just needs its block number 1–8 somewhere in the name. The tool finds the number and ignores scheme codes and years.

These all work and map to the right block:
1.pdf · 01.pdf · cert-2.pdf · GP-2026-cert-05.pdf → 5 · 3rd non splitting.pdf → 3
#Certificate
1Pre-estimation / Feasibility / Utility report
2No duplication / double-counting (BDO)
3Non-splitting of work (BDO)
4Permissible category of MGNREGA (BDO)
5Beneficiary selection per Para 5 (BDO)
6DPR preparation (set to Yes automatically)
7Convergence dept clearance (set to Yes automatically)
8Adherence to non-negotiables (BDO)
If a file has no number, a keyword also works (split, permissible, benefic…). After you pick the folder, the panel shows which PDF landed in each block, so you can confirm before filling.
~1 MB per PDF (server limit). The panel shows every file’s size. Oversized scans are compressed automatically (re-rendered smaller), e.g. 3.pdf · 1.80 MB → 0.62 MB ✓. If a file still can’t fit, it’s marked “too big” and Fill is blocked until you replace it with a clearer/smaller scan.

Part C · Fill a work entry

1

Set your signing details once (in the extension)

Click the extension’s icon in the browser toolbar (top-right). A small settings popup opens — type Name, Designation, Department, Mobile, Email. They save automatically and are reused for every work entry.
Icon hidden? Click the puzzle-piece 🧩 Extensions button and pin “Certificate Auto-Fill”.

2

On Work Entry: choose the folder, then Fill

Open the Work Entry page and pick the Work Category / Heads / Village at the top as usual. The panel appears top-right and shows who you’re signing as.
① Click Choose certificate folder — the panel then reveals the 1–8 mapping (green ticks show each match).
② Click Fill form — DPR & Convergence are set to Yes automatically.

3

Done message — mapping closes

On success the panel shows a “Done” message and hides the mapping again, ready for the next work entry.

4

Check, then click the page’s own Save

The tool only fills the form — nothing is submitted until you review it and click the Work Entry page’s Save button. You stay in control.

Troubleshooting. Panel missing? Confirm the address ends in work_entry.aspx and the add-on is enabled in chrome://extensions. A block shows “no PDF matched”? Rename that file so its number 1–8 is in the name, then pick the folder again. Oversized scans are compressed automatically; if one still can’t reach ~1 MB it’s marked “too big” and blocks Fill — replace it with a clearer/smaller scan. DPR and Convergence are set to Yes for you; if a work truly needs one as No, change it on the page and remove that file after filling.
